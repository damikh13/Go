Основные типы не составных переменных:

- bool
- string (неизменяемый slice byte’ов)
  - `"hello\n"` → `"hello"`
  - `hello\n` → `hello\n`
  - []rune(s) — получить символы
  - `for idx, rune := range "héllo"` ← range проходится по rune’ам
  - len(s) ← сколько байтов! `len(héllo)` = 6!
- int, uint ← в зависимости от разрядности системы
- int8, int16, int32, int64
- uint8, …, uint64
- byte = int8
- rune = int32 (инициализируется при помощи `x := 'A'`). Используется при декодировании строк (`for i, r := range str` или `r := []rune(s)`).
- float32, float64 (default)
- complex64, complex128 (10.9 + 13.4i)
- указатели ()
- uintptr

Объявление их происходит двумя (третий для констант) способами:

```go
username := "admin"
```

```go
		x := 20
		fmt.Println(x) // 20
	}
	fmt.Println(x) // 10

```

Есть интересный механизм для констант — автоматически увеличивающаяся переменная:

```go
const (
	Monday = iota // 0
	Tuesday
	Wednesday
)
fmt.Println(Wednesday) // 2
```

📌

Если встроенный синтаксис для `swap`’а:

```go
a, b = b, a
```

Иногда определяют кастомные типы данных, чтобы запретить операции:

```go
type OrderID int64
type UserID int64

var oid OrderID = 11
var uid UserID = 22

fmt.Println(oid + uid) // нельзя!
```

Определить тип переменной можно при помощи:

```go
fmt.Printf("type(%v) = %T\n", val, val) // type(12.34) = float64
```

Go поддерживает базовую конвертацию типов:

```go
var f float64 = -3.9
var i int = int(f) // -3
var u uint = uint(f) // 0

fmt.Println(string(65))       // "A"
fmt.Println(strconv.Itoa(65)) // "65"

```

<aside>
📌

Однако она может вести себя по-разному в зависимости от того, что мы пытаемся сконвертировать — константу (на этапе компиляции) или переменную (в runtime’е):

```go
int(3.9) // ошибка! cannot convert 3.9 (untyped float constant) to type int
```

```go
fl := 3.9
int(fl) // 3
```

</aside>

Важный нюанс, касающийся именования идентификаторов: если назвать с большой буквы, то он будет доступен при экспорте модуля, если с маленькой — то недоступен! К примеру, поле класса нельзя будет посмотреть или в целом проиницализировать экземпляр (`p := user.Profile{Name: "John", age: 30}`). Частая проблема у новичков — пропадающие поля в JSON. Геттеры принято называть Name(), сеттеры — SetName().

Идентификаторы внутри главного пакета не стоит называть с заглавной буквы, т.к. подразумевается, что всё, что там есть, просто используется для компиляции выходной программки.

Если где-то внутри if’а мы объявим переменную с таким же именем, как и вне его, то далее внутри этого же if’а мы больше не сможем получить доступ к переменной из внешней области. varName всегда будет означать “внутренняя переменная”. Такой эффект называется **shadowing**.
